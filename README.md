## About

A collection of practical programming exercises completed as part of computer science laboratory coursework.

This repository covers cryptography, network security fundamentals, web development, server-side programming, database connectivity, and Linux shell scripting.

## Laboratory Modules

### 01. Network Security & Cryptography

*Language: Java*

| Program | Description |
|---|---|

| Blowfish Cipher | Implementation of the Blowfish block cipher. |
| DES Encryption | Educational implementation of DES. |

## Getting Started

Clone the repository:

```bash
git clone <repository-url>
cd <repository-folder>
```

### Java

```bash
javac Program.java
java Program
```

### Web Technologies

Open the required `.html` file in a web browser.

### PHP

```bash
php -v
php -S localhost:8000
```

Visit `http://localhost:8000`.

### PHP & MySQL

1. Install and start MySQL.
2. Create the required database and tables.
3. Configure database credentials.
4. Run the PHP development server.
5. Access the application through your browser.

### Bash

```bash
chmod +x script.sh
./script.sh
```

For MySQL-dependent Bash programs, ensure the MySQL service is running and the required database and table exist.

## Learning Objectives

- Implement fundamental cryptographic algorithms.
- Develop web applications using frontend technologies.
- Understand server-side programming with PHP.
- Integrate applications with MySQL databases.
- Automate Linux tasks using Bash.
- Practice program compilation, execution, and debugging.
- Maintain projects using Git and GitHub.
