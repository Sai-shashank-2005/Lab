# 📱 Mobile Application Development Lab

A collection of Android application development practicals implemented using **Java, XML, and Android Studio** as part of the M.Tech (Six-Year Integrated) Computer Science and Engineering curriculum at Bharathidasan University.

This repository contains eight practical experiments covering Android UI design, event handling, database management, animations, intents, fragments, and multimedia applications.

## 🎯 Objectives

- Understand Android application architecture and development.
- Design user interfaces using XML layouts.
- Implement application logic using Java.
- Perform database operations using SQLite.
- Explore Android components such as Intents and Fragments.
- Implement animations and multimedia functionalities.

## 📚 Practical Experiments

| No. | Experiment | Description |
|:---:|---|---|
| 01 | Different Layout Designs | Display student biodata using nested layouts. |
| 02 | Arithmetic Operations | Perform addition, subtraction, multiplication, and division. |
| 03 | Business Calculator | Develop a calculator with numerical and arithmetic buttons. |
| 04 | Bouncing Ball Animation | Implement continuous ball movement using animation. |
| 05 | Intent | Open a website and phone dialer using Android Intents. |
| 06 | SQLite – Student Biodata | Store, view, and delete student information using SQLite. |
| 07 | Fragments – Tablet Programming | Switch between different screens using Fragments. |
| 08 | Media Player | Implement Play, Pause, and Stop audio operations. |

## ⚙️ Development Environment

**Prerequisites:**
- Android Studio
- Android SDK
- Java Development Kit (JDK)
- Android Emulator or Physical Android Device

**Getting Started:**

1. Clone the repository:

   ```bash
   git clone <YOUR_REPOSITORY_URL>
   ```

2. Open Android Studio.
3. Select **Open** and choose the project directory.
4. Allow Gradle synchronization to complete.
5. Run the application using an emulator or physical device.
